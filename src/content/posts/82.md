## Protocol Buffer Compiler 설치

> **linux 환경 기반**

```bash
$ sudo apt install -y protobuf-compiler
$ protoc --version
libprotoc 3.12.4
```

## ProtoBuf 파일 작성

### proto/greet.proto

```bash
syntax="proto3";
package greet;

message Greeting {
    string first_name = 1;
    string last_name = 2;
}

service GreetService {
    rpc Greet(Greeting) returns (Greeting) {}
}
```

---

## tonic-build로 ProtoBuf 파일 컴파일하기

### Cargo.toml 파일에 build dependency 추가

```bash
[package]
name = "hello-proto"
version = "0.1.0"
edition = "2021"

# See more keys and their definitions at https://doc.rust-lang.org/cargo/reference/manifest.html

[dependencies]

[build-dependencies]
tonic-build = "0.10"
```

### build.rs 작성

> build.rs는 루트 디렉터리에 생성!

```bash
fn main() {
    tonic_build::configure()
        .out_dir("src/")
        .compile(
            &["proto/greet.proto"],
            &["proto/"],
        )
        .unwrap();
}
```

-   out\_dir : 컴파일을 통해 생성된 rust 파일이 저장될 경로
-   compile : 컴파일할 ProtoBuf 파일들과 파일들의 경로
-   build\_client, build\_server : 기본적으로 true라 명시해 줄 필요는 없음
-   file\_descriptor\_set\_path : 서버 리플렉션을 구현하기 위해 필요한 옵션, 일단 패스

### ProtoBuf 파일 컴파일하기

```bash
$ cargo build
```
