## **Zola 설치**

```bash
$ git clone https://github.com/getzola/zola.git
$ cd zola
$ cargo install --path . --locked
$ zola --version
```

```bash
$ cp target/release/zola ~/.cargo/bin/zola
```

 zola 명령어를 전역으로 사용하기 위해 $PATH 경로로 바이너리를 이동합니다.

## **빌드 및 실행**

### **빌드**

```bash
$ zola build
```

 public 디렉토리에 빌드 결과물 생성.

### **로컬에서 실행**

```bash
$ zola serve
```
